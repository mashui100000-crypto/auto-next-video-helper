Auto Next Helper Privacy Policy

Last updated: May 11, 2026

Auto Next Helper does not collect, transmit, sell, or share personal information.

What the extension does

The extension runs locally in your browser to detect video playback state and next-episode controls on webpages. It can help with automatic next-episode playback, intro/outro skipping, playback speed, and interface language preferences.

Data storage

User settings such as language, playback speed, skip intro timing, skip outro timing, and auto-next preferences are stored using browser storage. These settings stay in the browser environment and are used only to provide the extension features.

Data collection and sharing

The extension does not use analytics, tracking, account systems, remote servers, or third-party data sharing. It does not collect browsing history or personal information.

Permissions

The extension requests webpage access so it can find video elements and next-episode controls on pages where you use it. This processing happens locally in the browser.

Contact

For support, please use the project page or the contact information listed in the extension store listing.
